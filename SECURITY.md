# Beveiligingslek melden

Vind je een beveiligingsprobleem in een repository van Durlinger? Meld het dan
**niet** in een gewoon issue, een pull request of een openbare discussie. Zo
blijft het lek uit beeld tot het is opgelost.

## Publieke repository's

Gebruik de knop **Report a vulnerability** op het tabblad **Security** van de
repository. Je melding is dan alleen zichtbaar voor de beheerders.

## Interne repository's (medewerkers)

Maak op het tabblad **Security** van de repository een **security advisory**
aan (Advisories → New draft security advisory). Kan dat niet, neem dan contact
op met de eigenaar uit `.github/CODEOWNERS` van die repository.

## Wat we nodig hebben

- Om welke repository en welk onderdeel het gaat.
- Wat het probleem is en wat iemand ermee zou kunnen doen.
- Hoe het na te spelen is (stappen, voorbeeldverzoek of code).

Stuur geen echte wachtwoorden, tokens of persoonsgegevens mee. Een beschrijving
van wat er zichtbaar is volstaat.

## Wat je van ons kunt verwachten

We bevestigen je melding, onderzoeken hem en laten weten wanneer het is
opgelost. Test alleen op je eigen account en gegevens, en verstoor geen
diensten voor anderen.
